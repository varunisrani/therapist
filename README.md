# MindfulMate Therapist Demo

MindfulMate is a front-end demonstration of a mental-health support portal with therapist discovery and self-care tools.

## Core features

- Landing and therapist catalogue pages with profile detail and booking-confirmation views.
- In-memory mood tracker with example history.
- Simulated chat responses for demonstrating an assistant interface.
- Music-player UI with category filtering and example track metadata.
- Dedicated tools, chat, music, mood, and emergency-resource pages.
- Responsive animated interface with dark-mode styling.

## Technology stack

- Next.js 15 App Router, React 19, and TypeScript
- Tailwind CSS
- Framer Motion, Heroicons, and React Icons

## Prerequisites

- Node.js 20 or newer
- npm (a `package-lock.json` is included)

## Local setup

```bash
git clone https://github.com/varunisrani/therapist.git
cd therapist
npm ci
npm run dev
```

The development server is available at `http://localhost:3000` by default.

To create and serve a production build:

```bash
npm run build
npm run start
```

The manifest also defines `npm run lint`.

## Configuration

The current source does not read any environment variables.

## Project structure

```text
app/          App Router pages and global styling
components/   Therapist cards, chat, mood, music, navigation, and emergency UI
components/ui Reusable button primitive
lib/          Shared styling utility
public/       Static assets
```

## Status and limitations

This repository is a UI demo, not a clinical or emergency service. Therapist profiles and tracks are mock data, mood entries are held only in component memory, and chat replies are selected from fixed local responses rather than generated by an AI service. Booking, sign-up, login, contact, and several footer destinations are not implemented, and referenced local audio/image files are absent.
